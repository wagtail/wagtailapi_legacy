# Roadmap

This roadmap represents the current vision for this project, and is subject to change. We welcome feedback and we’re open to suggestions!

This package is in maintenance mode. The goal is to keep the v2 API working with supported versions of Wagtail, so that projects have time to migrate to the [v3 API](https://docs.wagtail.org/en/latest/advanced_topics/api/v3/index.html). No new features are planned.
